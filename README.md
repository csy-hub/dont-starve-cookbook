# 荒野料理图鉴

无需登录、无需后端的《饥荒》中文料理资料查询网页。

- 默认 81 条联机版记录，全部版本共 139 条记录。
- 中文料理与材料搜索，版本、食物类型与锅具筛选。
- 生命、饥饿、理智等属性升降序排序。
- 成品图片、中文材料对照、配方规则与四格示例。
- 数据整理日期：2026-10-14，不自动同步游戏更新。

## 发布到 GitHub Pages

仓库 Settings → Pages → Deploy from a branch → main → / (root) → Save。
无需构建、依赖安装、API 密钥或后台服务。

## 本地使用

使用现代浏览器打开 index.html 即可。图片、数据、样式和交互脚本均已嵌入该文件，无外部运行依赖。
